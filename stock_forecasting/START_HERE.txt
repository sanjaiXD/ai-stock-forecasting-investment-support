┌──────────────────────────────────────────────────────────────────────────────┐
│ METHOD 1: AUTOMATED INSTALLATION (EASIEST - RECOMMENDED)                     │
└──────────────────────────────────────────────────────────────────────────────┘

This is the EASIEST way! Just double-click one file and everything is done!

FOR WINDOWS:
  1. Double-click: INSTALL_WINDOWS.bat
  2. Wait for installation (5-10 minutes)
  3. Application will start automatically!
  4. Browser opens at: http://127.0.0.1:5000

FOR MAC/LINUX:
  1. Right-click INSTALL_MAC_LINUX.sh → Properties → Permissions → 
     Check "Allow executing file as program"
  2. Double-click: INSTALL_MAC_LINUX.sh
  3. Wait for installation (5-10 minutes)
  4. Application will start automatically!
  5. Browser opens at: http://127.0.0.1:5000

✅ That's it! Skip to "USING THE APPLICATION" section below.


┌──────────────────────────────────────────────────────────────────────────────┐
│ METHOD 2: MANUAL INSTALLATION IN VS CODE                                     │
└──────────────────────────────────────────────────────────────────────────────┘

If you want to use VS Code:

  1. Open VS Code
  2. Click: File → Open Folder
  3. Select the "stock_forecasting" folder
  4. Open Terminal in VS Code: Terminal → New Terminal (or Ctrl+`)
  5. Run these commands:

     Windows:
     --------
     python -m venv venv
     venv\Scripts\activate
     pip install -r requirements.txt
     python app.py

     Mac/Linux:
     ----------
     python3 -m venv venv
     source venv/bin/activate
     pip install -r requirements.txt
     python app.py

  6. Open browser: http://127.0.0.1:5000

📖 For detailed VS Code instructions, see: VSCODE_SETUP_GUIDE.txt


┌──────────────────────────────────────────────────────────────────────────────┐
│ METHOD 3: COMMAND LINE INSTALLATION                                          │
└──────────────────────────────────────────────────────────────────────────────┘

If you prefer command line:

  1. Open Terminal/Command Prompt
  2. Navigate to project folder:
     cd path/to/stock_forecasting
  
  3. Run diagnostic check:
     python check_system.py
  
  4. If everything OK, install:
     pip install -r requirements.txt
  
  5. Run application:
     python app.py
  
  6. Open browser: http://127.0.0.1:5000

🚀 USING THE APPLICATION
═══════════════════════════════════════════════════════════════════════════════

Once the application is running:

  STEP 1: Enter Stock Ticker
  ──────────────────────────
  Type a stock symbol in the input box.
  
  Examples:
  • AAPL (Apple Inc.)
  • TSLA (Tesla Inc.)
  • GOOGL (Google)
  • MSFT (Microsoft)
  • AMZN (Amazon)
  • INFY.NS (Infosys - India)
  
  💡 Find more symbols at: https://finance.yahoo.com

  STEP 2: Select Date Range
  ──────────────────────────
  • Default is last 2 years (recommended)
  • You can change start and end dates
  • Minimum 100 days of data required
  • More data = better predictions

  STEP 3: Click "Predict Stock Price"
  ────────────────────────────────────
  • First prediction takes 30-60 seconds (AI is training!)
  • You'll see a loading animation
  • System trains 3 different AI models
  • Automatically selects the best model

  STEP 4: View Results
  ─────────────────────
  You'll see:
  ✅ Current stock price
  ✅ Predicted price for next 7 days
  ✅ BUY/SELL/HOLD recommendation
  ✅ Risk level (Low/Medium/High)
  ✅ Interactive charts
  ✅ Model performance comparison

🎯 UNDERSTANDING THE RESULTS
═══════════════════════════════════════════════════════════════════════════════

RECOMMENDATIONS:
  🟢 BUY   → Predicted price increase > 3%
  🟡 HOLD  → Predicted price change between -3% and +3%
  🔴 SELL  → Predicted price decrease > 3%

RISK LEVELS:
  🟢 Low Risk     → Volatility < 1% (stable stock)
  🟡 Medium Risk  → Volatility 1-2% (moderate fluctuation)
  🔴 High Risk    → Volatility > 2% (high fluctuation)

CHARTS:
  📊 Historical Prices  → Past stock performance
  📈 Moving Averages    → Trend indicators (MA7, MA21, MA50)
  🎯 Predictions        → Actual vs predicted comparison

AI MODELS:
  🤖 Linear Regression  → Fast, simple baseline
  🌲 Random Forest      → Ensemble learning, robust
  🧠 LSTM Neural Network → Deep learning, most accurate for time series

🛠️ TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

If something goes wrong, try these solutions:

┌─────────────────────────────────────────────────────────────────────────────┐
│ PROBLEM: Python not found                                                   │
├─────────────────────────────────────────────────────────────────────────────┤
│ SOLUTION:                                                                   │
│ • Install Python from: https://www.python.org/downloads/                   │
│ • CHECK "Add Python to PATH" during installation                           │
│ • Restart computer after installation                                      │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│ PROBLEM: Installation fails or takes too long                              │
├─────────────────────────────────────────────────────────────────────────────┤
│ SOLUTION:                                                                   │
│ • Update pip first: python -m pip install --upgrade pip                    │
│ • Use CPU TensorFlow: pip install tensorflow-cpu                           │
│ • Install one by one if needed (see requirements.txt)                      │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│ PROBLEM: "Port 5000 already in use"                                        │
├─────────────────────────────────────────────────────────────────────────────┤
│ SOLUTION:                                                                   │
│ • Open app.py                                                               │
│ • Change last line to: app.run(debug=True, port=8000)                      │
│ • Open browser at: http://127.0.0.1:8000                                   │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│ PROBLEM: "Invalid ticker symbol"                                           │
├─────────────────────────────────────────────────────────────────────────────┤
│ SOLUTION:                                                                   │
│ • Verify symbol at: https://finance.yahoo.com                              │
│ • Use uppercase (AAPL not aapl)                                            │
│ • For Indian stocks, add .NS (e.g., INFY.NS)                               │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│ PROBLEM: Application starts but page doesn't load                          │
├─────────────────────────────────────────────────────────────────────────────┤
│ SOLUTION:                                                                   │
│ • Wait 30 seconds for server to fully start                                │
│ • Check terminal for error messages                                        │
│ • Try: http://localhost:5000 instead of 127.0.0.1                          │
│ • Disable antivirus/firewall temporarily                                   │
└─────────────────────────────────────────────────────────────────────────────┘

RUN DIAGNOSTIC TOOL:
  python check_system.py
  
  This will check:
  ✓ Python version
  ✓ Installed packages
  ✓ Project files
  ✓ System requirements
