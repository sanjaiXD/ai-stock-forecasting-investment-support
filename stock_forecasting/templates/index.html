About This System

This AI-Driven Stock Forecasting and Investment Decision Support System leverages advanced machine learning algorithms to analyze historical stock market data and predict future price movements.

Key Technologies:
• Python Flask for robust backend API
• TensorFlow/Keras for LSTM deep learning models
• Scikit-Learn for traditional ML algorithms
• Yahoo Finance API for real-time market data
• Chart.js for interactive data visualization
