================================================================================
    AI-DRIVEN STOCK FORECASTING SYSTEM - QUICK SETUP GUIDE
================================================================================

📋 PREREQUISITES:
   - Python 3.8 or higher
   - pip (Python package manager)
   - 4GB RAM minimum
   - Internet connection (for downloading stock data)

================================================================================

🚀 QUICK START (3 STEPS):

   STEP 1: Install Dependencies
   -----------------------------
   Open terminal/command prompt in the project folder and run:
   
   pip install -r requirements.txt
   
   (This may take 5-10 minutes for TensorFlow installation)

   STEP 2: Run the Application
   ----------------------------
   python app.py
   
   OR use the convenient startup scripts:
   - Linux/Mac: ./run.sh
   - Windows: run.bat

   STEP 3: Open Browser
   ---------------------
   Navigate to: http://127.0.0.1:5000

================================================================================

💡 USAGE:

   1. Enter a stock ticker symbol (e.g., AAPL, TSLA, GOOGL, MSFT)
   2. Select date range (default: last 2 years)
   3. Click "Predict Stock Price"
   4. Wait 30-60 seconds for model training
   5. View predictions, recommendations, and charts!

🛠️ TROUBLESHOOTING:

   Problem: Port 5000 already in use
   Solution: Edit app.py and change the port number:
            app.run(debug=True, host='0.0.0.0', port=8000)

   Problem: TensorFlow installation fails
   Solution: Install CPU-only version:
            pip install tensorflow-cpu==2.15.0

   Problem: "Invalid ticker symbol"
   Solution: Verify the ticker symbol on finance.yahoo.com
            For Indian stocks, add .NS suffix (e.g., INFY.NS)

   Problem: "Not enough historical data"
   Solution: Select a longer date range (minimum 100 trading days)
