┌──────────────────────────────────────────────────────────────────────────────┐
│ 📦 INSTALLATION                                                              │
└──────────────────────────────────────────────────────────────────────────────┘

  Install All Dependencies:
  $ pip install -r requirements.txt

  Create Virtual Environment (Optional but Recommended):
  $ python -m venv venv
  $ source venv/bin/activate          # Linux/Mac
  $ venv\Scripts\activate.bat         # Windows


┌──────────────────────────────────────────────────────────────────────────────┐
│ 🚀 RUNNING THE APPLICATION                                                   │
└──────────────────────────────────────────────────────────────────────────────┘

  Method 1 - Direct Python:
  $ python app.py

  Method 2 - Using Scripts:
  $ ./run.sh                          # Linux/Mac
  $ run.bat                           # Windows

  Access Application:
  → http://127.0.0.1:5000

│ 🛠️ TROUBLESHOOTING                                                           │
└──────────────────────────────────────────────────────────────────────────────┘

  Problem                          Solution
  ─────────────────────────────────────────────────────────────────────────────
  Port 5000 in use                → Edit app.py, change port to 8000
  TensorFlow install fails        → pip install tensorflow-cpu==2.15.0
  Invalid ticker symbol           → Verify on finance.yahoo.com
  Not enough data                 → Select longer date range (100+ days)
  Module not found                → pip install -r requirements.txt

│ 🌐 API ENDPOINTS                                                             │
└──────────────────────────────────────────────────────────────────────────────┘

  POST /api/predict
  ├─ Body: { ticker, start_date, end_date }
  └─ Returns: Predictions, recommendations, charts

  GET /api/data?ticker=AAPL&start_date=...&end_date=...
  └─ Returns: Historical data with technical indicators

  GET /api/forecast
  └─ Returns: Last prediction results

  GET /health
  └─ Returns: Server health status
