INSTALLATION
============

1. Install dependencies:
   pip install -r requirements.txt

2. Run application:
   python app.py

3. Open browser:
   http://127.0.0.1:5000


USAGE EXAMPLE
=============

Input:
   Ticker: AAPL
   Start Date: 2022-01-01
   End Date: 2024-01-01

Output:
   ✅ Current Price: $185.50
   ✅ Predicted Price (7 days): $192.30
   ✅ Recommendation: BUY
   ✅ Risk Level: Low
   ✅ Price Change: +$6.80 (+3.67%)
   ✅ Best Model: LSTM
   ✅ Charts: Historical, Moving Averages, Predictions


API ENDPOINTS
=============

POST /api/predict
   Request: { ticker, start_date, end_date }
   Response: { predictions, recommendation, risk, charts }

GET /api/data?ticker=AAPL&start_date=...&end_date=...
   Response: { historical data with indicators }

GET /api/forecast
   Response: { last prediction results }

GET /health
   Response: { status, timestamp }
