STEP-BY-STEP INSTALLATION FOR VS CODE
═════════════════════════════════════════════════════════════════════════════

STEP 1: DOWNLOAD AND EXTRACT PROJECT
─────────────────────────────────────────────────────────────────────────────

1. Download the file: stock_forecasting.zip
2. Extract it to a folder (e.g., C:\Projects\ or ~/Projects/)
3. You should now have a folder named "stock_forecasting"


STEP 2: OPEN PROJECT IN VS CODE
─────────────────────────────────────────────────────────────────────────────

1. Open VS Code
2. Click: File → Open Folder
3. Navigate to and select the "stock_forecasting" folder
4. Click "Select Folder"


STEP 3: INSTALL PYTHON EXTENSION
─────────────────────────────────────────────────────────────────────────────

1. In VS Code, click the Extensions icon (left sidebar) or press Ctrl+Shift+X
2. Search for "Python"
3. Install the official "Python" extension by Microsoft
4. Wait for installation to complete


STEP 4: OPEN INTEGRATED TERMINAL
─────────────────────────────────────────────────────────────────────────────

1. In VS Code, go to: Terminal → New Terminal
   OR press: Ctrl+` (backtick key)
2. You should see a terminal at the bottom of VS Code


STEP 5: CREATE VIRTUAL ENVIRONMENT (RECOMMENDED)
─────────────────────────────────────────────────────────────────────────────

In the terminal, type these commands one by one:

Windows:
--------
python -m venv venv
venv\Scripts\activate

Mac/Linux:
----------
python3 -m venv venv
source venv/bin/activate

After activation, you should see (venv) at the start of your terminal line.


STEP 6: INSTALL DEPENDENCIES
─────────────────────────────────────────────────────────────────────────────

In the terminal (with venv activated), type:

pip install --upgrade pip
pip install -r requirements.txt

⏱️ This will take 5-10 minutes (TensorFlow is large)

You'll see packages being downloaded and installed.


STEP 7: VERIFY INSTALLATION
─────────────────────────────────────────────────────────────────────────────

Check if everything is installed:

pip list

You should see: Flask, numpy, pandas, tensorflow, yfinance, etc.


STEP 8: RUN THE APPLICATION
─────────────────────────────────────────────────────────────────────────────

In the terminal, type:

python app.py

You should see:
============================================================
🚀 AI-Driven Stock Forecasting System
============================================================
Starting Flask server...
Access the application at: http://127.0.0.1:5000
============================================================


STEP 9: OPEN IN BROWSER
─────────────────────────────────────────────────────────────────────────────

1. Hold Ctrl (or Cmd on Mac) and click on: http://127.0.0.1:5000
   OR
2. Open your browser and go to: http://127.0.0.1:5000

You should see the AI Stock Forecasting dashboard!


STEP 10: TEST THE APPLICATION
─────────────────────────────────────────────────────────────────────────────

1. Enter a stock ticker: AAPL
2. Leave the default date range (last 2 years)
3. Click "Predict Stock Price"
4. Wait 30-60 seconds for the first prediction
5. View the results!

🚨 COMMON ISSUES AND SOLUTIONS
═════════════════════════════════════════════════════════════════════════════

ISSUE 1: "python is not recognized"
─────────────────────────────────────────────────────────────────────────────
SOLUTION:
- Python is not in PATH
- Reinstall Python and check "Add Python to PATH" during installation
- OR use full path: C:\Python39\python.exe app.py


ISSUE 2: "pip is not recognized"
─────────────────────────────────────────────────────────────────────────────
SOLUTION:
- Try: python -m pip install -r requirements.txt


ISSUE 3: Permission denied on Mac/Linux
─────────────────────────────────────────────────────────────────────────────
SOLUTION:
- Use: python3 instead of python
- Use: pip3 instead of pip


ISSUE 4: TensorFlow installation fails
─────────────────────────────────────────────────────────────────────────────
SOLUTION:
- Update pip first: pip install --upgrade pip
- Install CPU version: pip install tensorflow-cpu==2.15.0
- OR try older version: pip install tensorflow==2.13.0


ISSUE 5: Port 5000 already in use
─────────────────────────────────────────────────────────────────────────────
SOLUTION:
1. Open app.py in VS Code
2. Go to the last line
3. Change: app.run(debug=True, host='0.0.0.0', port=5000)
   To:     app.run(debug=True, host='0.0.0.0', port=8000)
4. Save and run again
5. Open: http://127.0.0.1:8000


ISSUE 6: ModuleNotFoundError
─────────────────────────────────────────────────────────────────────────────
SOLUTION:
- Make sure virtual environment is activated (you see (venv))
- Run: pip install -r requirements.txt again


ISSUE 7: "Invalid ticker symbol"
─────────────────────────────────────────────────────────────────────────────
SOLUTION:
- Use valid symbols from Yahoo Finance
- Examples: AAPL, TSLA, GOOGL, MSFT
- For Indian stocks: INFY.NS, TCS.NS


ISSUE 8: Certificate/SSL errors
─────────────────────────────────────────────────────────────────────────────
SOLUTION:
- Update pip: pip install --upgrade pip
- Update certifi: pip install --upgrade certifi
